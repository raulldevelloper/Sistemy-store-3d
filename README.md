# RT Dias 3D Store Management

## English

### About

RT Dias 3D Store Management is a full stack project (back end for now) developed to manage a local store that sells utility products and provides 3D printing services.

The project is being built step by step as part of my learning journey in:

- Java
- MySQL
- Spring Boot

### Current Stage

- Database modeling
- Version 1: Java console application
- Version 2: Spring Boot API

### Technologies

- Java
- MySQL
- Spring Boot
